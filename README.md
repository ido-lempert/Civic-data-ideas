# Civic data ideas

A proposal, not a built tool. The goal is a small, useful tool on public data that a community could run for itself.

## The idea
A one-page lookup that answers one local question from an open dataset, with the data's source and date shown next to every answer, and a plain "this may be out of date" note.

## Before building anything
1. Pick one question and one place. A narrow choice is better than a general portal.
2. Find a public dataset for it. Check the licence, how often it is updated and whether it has a stable download or API. **I have not yet verified any specific dataset**, so none is named here.
3. Check who already publishes this. If a good tool exists, contribute to it instead.
4. Ask one or two people who would use it whether the question is real.

## Shape of a first version
- A static page plus a small script that reads a downloaded copy of the data. No accounts, no tracking, no server to run.
- The data file is dated and the date is shown on the page.
- The repository includes how to refresh the data.

## Open questions
Which question? Which place? Which dataset? These need an owner's decision and a real dataset check.
